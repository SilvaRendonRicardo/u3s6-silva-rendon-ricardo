
# u3s6-silva-rendon-ricardo
Probé el sistema de autenticación y sesiones de Django, verificando el registro de usuarios, el inicio y cierre de sesión. También comprobé que cada usuario pueda ver, editar y eliminar únicamente sus propios servicios. El objetivo fue validar que las sesiones funcionen correctamente y que las rutas estén protegidas para usuarios no autenticados.
